## طراحی جدید چه چیزی است
- `<style id="mn-css">` — نوار بالای شیشه‌ای (`mn-bar`)، منوی پایین ثابت (`mn-nav`)، کشوی آکاردئونی (`mn-dr`)،
  گردکردن کارت‌ها (`--mr`)، گِرد شدن دکمهٔ شروع، حذف سایه‌های سنگین، `body` padding بالا/پایین برای پوسته.
- `<script id="mn-js">` — آیکون‌های SVG درون‌خطی (بدون فونت آیکون)، تبدیل خودکار اموجی‌های رابط به آیکون،
  نقطه‌های رنگی برای ✅/❌/⚠، ناوبری با `history.pushState` و deep-link `#ph-pXX`، سواپِ لمسی برای بستن کشو،
  آکاردئونی‌کردن کارت‌ها و سرفصل‌های `.wrap h2` (پایان اسکرول طولانی)، هم‌گام‌سازی با `window.phShow`.
- منوی پایین: `DNS` · `خط من` · `بازی` · `رزولورها` · `منو` (۵ خانه، طبق طراحی کاربر).
- پوستهٔ قدیمی (appbar/nav/drawer ما) داخل `<div id="ph-nav-root">` پیچیده و با CSS کاربر مخفی شده است.
