# ☁️ پینگ‌هاب روی Cloudflare Workers

همه‌چیز در **یک Worker** است: سایت + مینی‌اپ تلگرام + وب‌هوک بات. بدون سرور، بدون هزینه، ۲۴ساعته.

| مسیر | کار |
|---|---|
| `/` و `/app` | سایت و مینی‌اپ (تست DNS روی گوشی کاربر) |
| `/api/me` | شناسایی خط: ASN، اپراتور، شهر، لبهٔ کلادفلر |
| `/api/edge` | سلامت سرورهای DNS از دید لبهٔ کلادفلر |
| `/api/save` | ذخیرهٔ نتیجه در KV + ساخت لینک اشتراک (اعتبارسنجی امضای تلگرام) |
| `/r/<id>` | صفحهٔ اشتراک‌پذیر نتیجه (۹۰ روز نگه‌داری) |
| `/tg/webhook` | وب‌هوک بات (با هدر مخفی) |
| `/tg/setup?key=` | تنظیم مجدد وب‌هوک و دستورها |

## انتشار
```bash
python3 deploy.py build     # ساخت dist/worker.mjs
python3 deploy.py deploy    # آپلود روی Cloudflare
python3 deploy.py setup     # تنظیم وب‌هوک/دستورها/دکمهٔ منو
python3 deploy.py test      # تست زندهٔ همهٔ مسیرها
```
کلیدها از `../.env` خوانده می‌شوند (در گیت کامیت نمی‌شود).

## نکته
`app.html` داخل `worker.src.mjs` جاگذاری می‌شود (متغیر `__APP_HTML__`)، پس خروجی یک فایل تک‌پارچه است و
هیچ وابستگی خارجی ندارد.

## چرا اندازه‌گیری در مرورگر است؟
سرور فقط می‌تواند بگوید «فلان DNS از دید اینترنت سالم است». عددی که برای کاربر معنا دارد،
پینگ **از خط خودش** است — پس تست DNS با `fetch` روی DoH در مرورگر/WebView کاربر اجرا می‌شود.
