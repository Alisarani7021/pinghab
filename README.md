## ❓ این چیکار می‌کنه؟ (به زبان ساده)

هر خط اینترنت بهترین DNS خودش را دارد؛ هیچ‌کس هم درست نمی‌داند کدام.
این ابزار **روی گوشی خودت** به ده‌ها سرور DNS وصل می‌شود، **پینگ، جیتر و افت بسته**شان را اندازه می‌گیرد
و می‌گوید کدام برای **خط تو** بهتر است — و کدام DNS دستکاری‌شده (هجک) است و باید از آن دوری کنی.

⚠️ **صادقانه:** DNS پینگ داخل مچ بازی را کم نمی‌کند. DNS این‌ها را بهتر می‌کند:
ورود به بازی، رفع تحریم، سرعت دانلود آپدیت، خطاهای لابی، و کیفیت مسیر CDN.

## ☁️ معماری سرویس آنلاین

```
Cloudflare Worker (pinghab)
 ├── /        → سایت عمومی (تست در مرورگر کاربر)
 ├── /app     → مینی‌اپ تلگرام (فقط اندازه‌گیری سمت کاربر)
 ├── /api/me  → تشخیص خط: ASN، اپراتور، شهر، لبهٔ کلادفلر
 ├── /api/edge→ سلامت DNSها از دید اینترنت
 ├── /api/save→ ذخیرهٔ نتیجه (اعتبارسنجی امضای initData تلگرام) + لینک اشتراک
 ├── /r/<id>  → صفحهٔ اشتراک‌پذیر نتیجه (۹۰ روز)
 └── /tg/webhook → بات @Pinghab_bot
```
جزئیات در `cloudflare/README.md` — انتشار با `python3 cloudflare/deploy.py all`.



یک جعبه‌ابزار کامل و **رایگان** که برای تو:

* به **۴۸ سرور DNS** (ایرانی، جهانی، گیمینگ، خانواده، حریم‌خصوصی) کوئری واقعی می‌فرستد؛
* **تأخیر میانه، جیتر، افت بسته، پایداری، DoH، DoT و اعتبار گواهی TLS** را اندازه می‌گیرد؛
* DNSهای **دستکاری‌شده (Hijack)** و مخصوص اپراتور (CDN داخلی) را تشخیص می‌دهد؛
* **تأخیر مسیر** شبکهٔ تو تا لبه‌های بزرگ اینترنت و سرور بازی را می‌سنجد؛
* همه را در یک **گزارش HTML فارسی با نمودار** جمع می‌کند و بهترین انتخاب را پیشنهاد می‌دهد؛
* با یک **بات تلگرام** و یک **اپ وب تک‌فایلی** قابل استفاده است.

> ⚠️ **صادقانه:** عوض کردن DNS **پینگ داخل مچ بازی را کم نمی‌کند** (بازی بعد از پیدا کردن سرور، با IP بازی وصل می‌شود).
> آنچه DNS واقعاً بهتر می‌کند: **داخل شدن به بازی و رفع تحریم**، **سرعت دانلود آپدیت/باز شدن لانچر**،
> **کم شدن خطای ورود و لابی**، و **کیفیت مسیر برخی CDNها**. برای پینگ واقعی، محل خروجی تونل و کیفیت مسیر مهم است.
> این ابزار آن مسیر را هم برایت **اندازه می‌گیرد** تا گمراه نشوی.

## 📡 پایش زنده بر اساس منطقه (داشبورد)

```bash
python3 dnsserve.py --port 8777 --cycle 3 --open
# سپس در مرورگر:  http://127.0.0.1:8777
```

چه می‌بینی:
* **پینگ لحظه‌ای** هر DNS (کوئری واقعی UDP/53، هر ۳ ثانیه) با **نمودار زنده** و روند (sparkline)
* **جدا بر اساس منطقه**: ایران / ترکیه / اروپا / آمریکا و کانادا / آسیا / روسیه / anycast
* **«قدرت» هر سرور**: امتیاز ۰–۱۰۰ از ترکیب پینگ + جیتر + افت بسته، با برچسب (عالی… ضعیف)
* **جیتر و افت بسته** به‌صورت زنده در یک پنجرهٔ ۹۰ ثانیه‌ای
* **افزودن سرور بازی خودت**: آی‌پی را وارد کن، خودش اول با UDP/53 و اگر جواب نداد با TCP/443 می‌سنجد و زنده نشان می‌دهد
* تشخیص خودکار: اگر خارج از ایران اجرا شود، پیام می‌دهد که سرورهای ایرانی طبیعی است پاسخ ندهند

API (برای ساخت اپ/بات روی آن):
```
GET  /api/state          → کل دادهٔ زنده به‌صورت JSON
GET  /api/health         → سلامت سرور
GET  /api/targets        → اهداف دلخواه من
POST /api/targets        → {"ip":"1.2.3.4","label":"PUBG Dubai","port":443}
POST /api/targets/remove → {"id":"custom-12345678"}
```

گزینه‌ها: `--port` · `--cycle` (فاصلهٔ نمونه‌گیری) · `--workers` · `--timeout` · `--open`

> روی گوشی (ترموکس): `python dnsserve.py --cycle 3` و بعد آدرس `http://127.0.0.1:8777` را در مرورگر گوشی باز کن.
> از منوی `run_dnsradar.sh` گزینهٔ ۱۰ هم همین کار را می‌کند.

## 🎛 دستورها و گزینه‌ها

```bash
python3 dnsscan.py --preset gaming            # gaming | iran | global | privacy | family | turkey | all
python3 dnsscan.py --servers radar,electro,cloudflare,google
python3 dnsscan.py --tag gaming               # فیلتر بر اساس برچسب
python3 dnsscan.py --attempts 12 --timeout 2  # دقیق‌تر (کندتر)
python3 dnsscan.py --no-dot --no-doh          # اسکن سریع‌تر
python3 dnsscan.py --game-ips 1.2.3.4:"PUBG ME",5.6.7.8:"PUBG SG"   # تست مسیر سرور بازی
python3 dnsscan.py --edges 5.6.7.8:"سرور من" --name "رایتل شیراز"
python3 dnsscan.py --formats csv,json         # فقط خروجی داده‌ای
```

| کلید | کار |
|---|---|
| `--preset` | مجموعهٔ آمادهٔ سرورها |
| `--servers` | انتخاب دستی با کاما |
| `--tag` | `gaming`, `iran`, `adblock`, `privacy`, `family`, `security` |
| `--attempts` | تعداد کوئری UDP برای هر سرور (پیش‌فرض ۸) |
| `--game-ips` | آی‌پی سرور بازی برای سنجش مسیر (اول جدول می‌آید) |
| `--out-dir` / `--name` / `--formats` | پوشه، برچسب اجرا، قالب‌های خروجی |

## 🧮 امتیاز چطور حساب می‌شود؟

```
امتیاز = ۱۰۰
  − (درصد افت بسته × ۴۵)        ← افت بسته، بدترین دشمن بازی
  − min(۴۰ , تأخیر میانه ÷ ۴)   ← تأخیر خام
  − جیتر (تا ۱۵)                ← نوسان
  − ۲۵ اگر DNS دستکاری‌شده باشد  ← خطر امنیتی
  + ۴ اگر CDN داخلی بدهد (مسیر بهتر داخل ایران)
  ± تا ۱۰ نسبت به مبنای 8.8.8.8 (تأخیر نسبی شبکهٔ تو)
  + ۴ برای DoH ، + ۲ برای DoT ، + ۲ برای گواهی معتبر TLS
```

**راهنمای برچسب‌ها:** `رفع تحریم` = دامنهٔ تست را درست جواب داد · `⚠ دستکاری‌شده` = به دامنهٔ ساختگی هم IP داد (خطر جعل) ·
`CDN داخلی` = IPهای داخلی برگرداند (مثلاً برای aparat) یعنی اپراتور تو را می‌شناسد · `DoH/DoT` = کانال رمزنگاری‌شده ·
`تأییدنشده` = دادهٔ این سرور از منبع رسمی نیست و باید با اسکن خودت تأیید شود.

## 🤖 راه‌اندازی بات تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده → `/newbot` → نام و یوزرنیم بده → **توکن** را بگیر.
2. روی سرور/کامپیوتر/گوشی (ترموکس):
```bash
export TELEGRAM_BOT_TOKEN="123456:ABC-DEF..."
python3 bot.py
```
3. تمام. در چت با بات بزن `/start`.

دستورهای بات: `/check` اسکن سریع · `/scan` مجموعه‌ها · `/report` گزارش HTML · `/ping 8.8.8.8` تست مسیر ·
`/dns 10.202.10.10` تست زندهٔ یک DNS + تشخیص دستکاری · `/guide` راهنمای پینگ.

> برای اینکه بات ۲۴ ساعته بالا بماند: روی یک VPS کوچک (یا حتی یک رزبپری/لپ‌تاپ روشن) با
> `nohup python3 bot.py > bot.log 2>&1 &` اجرا کن. اندروید هم با `termux-wake-lock` کار می‌کند.

## 🔧 تنظیم DNS روی دستگاه‌ها

| دستگاه | مسیر |
|---|---|
| **اندروید ۹+** | تنظیمات › شبکه و اینترنت › **DNS خصوصی** › «نام میزبان ارائه‌دهندهٔ DNS» → آدرس DoT مثل `shecan.ir` یا IP |
| **آیفون/آیپد** | تنظیمات › وای‌فای › (i) کنار شبکه › Configure DNS › Manual |
| **ویندوز ۱۱** | Settings › Network › Wi‑Fi/Ethernet › DNS server assignment › Manual (+ روشن کردن DNS over HTTPS) |
| **کنسول (PS5/Xbox)** | تنظیمات شبکه › DNS دستی (همان IPها) |
| **روتر** | بخش DHCP/DNS روتر → DNS دلخواه برای همهٔ دستگاه‌ها |

⚠️ **نکتهٔ امنیتی:** از DNS ناشناس استفاده نکن؛ DNS همهٔ درخواست‌هایت را می‌بیند. اگر ابزار «دستکاری‌شده» را علامت زد، آن را مصرف نکن و اگر قبلاً استفاده کردی، رمز اکانت بازی/ایمیلت را عوض کن.

## ➕ افزودن سرور جدید

در `servers.json` یک آیتم اضافه کن (شناسه یکتا، نام، ip، ip2 اختیاری، tags، note و در صورت وجود `dot`/`doh`)، بعد:
```bash
python3 dnsscan.py --servers شناسهٔجدید --attempts 10
```
اگر `verified: false` باشد، در گزارش با برچسب «تأییدنشده» نشان داده می‌شود.
